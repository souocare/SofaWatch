
# Database Migrations

SofaWatch uses Alembic to manage database schema changes.

## Current migration

Check the currently applied revision:

```bash
alembic current
```

## Apply migrations
Apply all pending migrations:

```bash
alembic upgrade head
```

## Create a migration
After changing SQLAlchemy models:

```bash
alembic revision --autogenerate -m "describe change"
```

Always inspect autogenerated migrations before applying them.
Autogeneration should not be treated as a replacement for reviewing the generated SQL operations.

## Roll back one migration
```bash
alembic downgrade -1
```

## Roll back to a specific revision
```bash
alembic downgrade <revision>
```

## Development workflow
The recommended workflow is:

```text
change SQLAlchemy models
        ↓
generate migration
        ↓
inspect migration
        ↓
apply migration
        ↓
run tests
```

Do not delete a migration that has already been applied without first downgrading the database to the previous revision.
